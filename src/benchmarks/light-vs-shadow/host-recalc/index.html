Light vs. Shadow DOM: Host State Recalculation

Evaluates selector matching and style recalculation speed when toggling host state across 500 component instances (comparing .comp.active .nX in Light DOM vs. :host(.active) .nX in Shadow DOM vs. :host(.active) ::slotted(.nX) across the slot seam).

.comp.active .n1..n19 :host(.active) .n1..n19 :host(.active) ::slotted(.n11..n19)

What is being tested?

With 500 instances already mounted (10,000 nodes for 20-node components; 20,000 nodes for 40-node components), the test toggles the .active class on all instances and forces style recalculation via getComputedStyle($container).color without triggering layout.

Baseline Takeaway

Matching :host(.active) .node inside Shadow DOM runs at ~91.5% of the speed of matching .comp.active .node in Light DOM when all instances recalculate style. Crossing the seam via ::slotted(.node) incurs a ~23–32% style recalculation penalty.
